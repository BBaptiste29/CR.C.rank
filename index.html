🎯 Concept

Vision de l'application

CrossFit Rank est une application mobile qui classe les athlètes CrossFit selon leurs records personnels, en les comparant aux meilleurs athlètes mondiaux du CrossFit.
🎮
Inspiré de Solo Leveling
Le système de rangs E → SSS reprend l'univers du manhwa Solo Leveling. Chaque athlète progresse comme un "chasseur" qui monte en rang en battant ses records.
📊
Comparaison mondiale
Chaque PR est comparé aux records mondiaux établis par les meilleurs athlètes CrossFit (Mat Fraser, Tia-Clair Toomey, Rich Froning…) pour calculer un score en %.
🫀
Carte musculaire
Un corps humain anatomique interactif (avant + arrière) s'illumine selon ton rang pour chaque groupe musculaire. Clique sur un muscle pour voir tes PRs associés.
🏆
Classement par Box
Filtre le classement par salle de CrossFit. Option de masquer son profil pour apparaître anonyme tout en restant dans les statistiques globales.
⚔️ Système de rangs

Les 8 rangs

Le rang est calculé automatiquement en comparant ton PR au record mondial CrossFit du même mouvement. La formule : (ton PR ÷ record mondial) × 100. Pour les temps, la formule est inversée.
RangNomSeuilSignificationCouleur
E Éveil0 – 19% Débutant absolu. Le voyage commence ici.
D Fer20 – 34% Les bases sont posées. Entraînement régulier.
C Bronze35 – 49% Niveau intermédiaire reconnu dans la box.
B Argent50 – 64% Au-dessus de la moyenne mondiale. Athlète sérieux.
A Or65 – 79% Athlète élite. Respecté dans chaque box.
S Platine80 – 89% Niveau compétition nationale. Potentiel Games.
SS Diamant90 – 98% Niveau CrossFit Games. Athlète professionnel.
SSS Monarque99%+ Record mondial ou quasi-record. Légendaire.
💡 Le rang global est la moyenne de tous les scores % de tes PRs. Un athlète qui entre 5 PRs à 45% chacun obtiendra un rang C global, même si certains mouvements individuels lui donnent un rang B.

🔐 Administration

Compte Admin caché

L'admin est totalement invisible — il apparaît comme un utilisateur normal dans le classement. Aucun badge, aucun indicateur visible.

🔑 Accès au panel admin

1
Méthode A — Appui long mobile : Appuie pendant 3 secondes sur le logo ⚔️ C.RANK en haut de l'écran
2
Méthode B — 5 clics rapides : Clique 5 fois rapidement sur le logo (en moins de 1,5 seconde)
3
Méthode C — URL cachée : Ajoute ?admin=open à la fin de l'URL de l'app
4
Code TOTP : Entrer le code à 6 chiffres qui change toutes les 60 secondes. En production, ce code sera généré uniquement par Google Authenticator sur le téléphone de l'admin.
📊
Modifier les records mondiaux
L'admin peut corriger ou mettre à jour les records mondiaux (homme et femme) pour chaque mouvement. La mise à jour recalcule automatiquement le rang de tous les utilisateurs ayant un PR sur ce mouvement.
⚠️
Valider les PRs suspects
Tout PR dont le score dépasse 110% du record mondial est automatiquement signalé comme suspect. L'admin peut valider (conserver) ou rejeter (supprimer) ces PRs depuis le panel.
👥
Gestion des utilisateurs
L'admin peut éditer un profil, envoyer un avertissement, ou bannir définitivement un utilisateur de l'application. L'historique des actions est conservé dans le journal d'audit.
⚠️ Le code TOTP affiché dans la démo est visible pour faciliter les tests. En version de production, ce code sera uniquement disponible dans Google Authenticator — jamais affiché dans l'app.
🌍 Automatisation

Mise à jour automatique des records

Un système automatique scrape internet chaque jour à 6h UTC pour détecter de nouveaux records mondiaux CrossFit.
1
GitHub Actions — Cron 6h UTC
Le script Python se lance automatiquement chaque jour. Peut aussi être déclenché manuellement depuis GitHub.
2
Scraping 4 sources indépendantes
CrossFit.com (officiel) · Morning Chalk Up (presse) · DuckDuckGo / WODwell · Claude AI avec web search natif
3
Moteur de consensus Claude AI
Claude analyse les données des 4 sources et calcule un score de confiance (0 à 1). Règles : amélioration max 20%, valeurs réalistes, cohérence entre sources.
4
Décision automatique
Confiance ≥ 0.75 → mise à jour automatique via Edge Function Supabase · Confiance 0.5–0.74 → alerte admin par GitHub Issue · Confiance < 0.5 → rejeté
5
Recalcul en cascade
Si un nouveau record est validé, tous les PRs des utilisateurs sur ce mouvement sont recalculés. Les rangs baissent si le record mondial augmente.
6
Notification push
Chaque utilisateur affecté reçoit une notification : "Nouveau record mondial — ton rang a changé !"
🛡️ Sécurité

Protections en place

La base de données et l'API sont protégées à plusieurs niveaux pour empêcher toute tentative de triche ou d'injection.
🔒
Row Level Security (RLS)
Chaque utilisateur ne peut lire/écrire que ses propres données. Les records mondiaux sont en lecture seule pour tous.
🧮
Types ENUM stricts
genre_type, rank_type, unit_type — impossible d'injecter des valeurs non prévues comme gender="admin".
🛡️
Anti SQL injection
Fonction is_safe_text() bloque les patterns dangereux (UNION, DROP, SELECT, scripts XSS) dans tous les champs texte libres.
🔐
Champs calculés protégés
score_percent et rank_letter sont toujours calculés côté serveur via trigger SECURITY DEFINER. Le client ne peut jamais les modifier.
📜
Historique immuable
La table pr_history est append-only. Des triggers bloquent tout UPDATE ou DELETE — l'historique ne peut pas être falsifié.
🕐
Rate limiting
Maximum 30 insertions de PRs par heure par utilisateur. Bloque les scripts automatisés de spam.
📋
Journal d'audit
Chaque INSERT/UPDATE/DELETE sur les PRs est loggé avec l'ancienne et la nouvelle valeur. Inaccessible depuis le client.
🔑
Admin TOTP
Mot de passe à usage unique basé sur l'horloge (RFC 6238). Change toutes les 60 secondes. Impossible à deviner par force brute.
🚫
Validation des PRs suspects
Tout score > 110% du record mondial est automatiquement signalé. L'admin doit valider manuellement avant publication.
⚙️ Architecture

Stack technique

L'application utilise une stack moderne, entièrement cloud, sans serveur à gérer.
Frontend démo
HTML / CSS / JS
App mobile-first pure, optimisée tactile, sans dépendance externe
Base de données
Supabase (PostgreSQL)
Tables, triggers, RLS, fonctions SQL, API auto-générée
Backend serverless
Supabase Edge Functions
TypeScript / Deno — mise à jour des records, recalcul en cascade
Automation
GitHub Actions + Python
Cron quotidien, scraping, consensus IA, alertes admin
Intelligence artificielle
Claude API (Anthropic)
Analyse et validation des nouveaux records via web search
App mobile (prod)
Flutter / FlutterFlow
iOS + Android natif, connecté à Supabase

Légende musculaire — ordre corrigé
La légende s'affiche maintenant en 2 colonnes dans l'ordre croissant E → D → C → B (colonne gauche) et A → S → SS → SSS (colonne droite), correspondant à la progression naturelle des rangs.

Les utilisateurs ayant activé "Masquer mon profil" n'apparaissent plus du tout dans le classement (ni en anonyme, ni sous quelque forme que ce soit). Leur profil reste privé à 100%.
